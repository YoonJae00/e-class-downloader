# 🚀  e-Class 영상 자동 다운로더

 e-Class(`learn.hansung.ac.kr`)의 강의 영상을 자동으로 탐색하고 MP4로 변환하여 저장해주는 편리한 CLI 도구입니다.

## ✨ 주요 기능
- **완전 자동 로그인**: 학번/비번 입력 시 브라우저 자동화를 통해 로그인을 수행합니다.
- **세션 유지**: 한 번 로그인하면 세션 쿠키를 저장하여 다음 실행 시 즉시 접속됩니다.
- **스마트 영상 추출**: JW Player 내부의 스트리밍 주소를 자동으로 찾아냅니다.
- **세부 선택 다운로드**: 특정 영상만 골라서 받거나, `all` 명령어로 전체를 한 번에 받을 수 있습니다.
- **자동 환경 설정**: 실행 시 필요한 라이브러리가 없으면 자동으로 설치합니다.
- **OS 맞춤형 실행**: Mac용(.command) 및 Windows용(.bat) 실행 파일을 제공합니다.

## 🛠 설치 및 시작하기

### 1. 사전 준비
- **Python 3.12 이상**이 설치되어 있어야 합니다. ([Python.org](https://www.python.org/downloads/)에서 다운로드)

### 2. 실행 방법

#### **Mac OS**
1. 이 저장소를 다운로드하고 압축을 풉니다.
2. `download_lecture.command` 파일을 마우스 오른쪽 버튼으로 클릭하여 [열기]를 선택합니다. (최초 실행 시 권한 허용 필요)
3. 안내에 따라 로그인을 진행하고 영상을 다운로드합니다.

#### **Windows**
1. 이 저장소를 다운로드하고 압축을 풉니다.
2. `run_windows.bat` 파일을 더블 클릭하여 실행합니다.
3. 안내에 따라 로그인을 진행하고 영상을 다운로드합니다.

## 📁 저장 경로 및 파일명 규칙
- **저장 위치**: 프로그램 폴더 내 `downloads/` 폴더에 과목별로 저장됩니다.
- **파일명**: `{강의명}_{주차}_{순서}_{영상제목}.mp4`

## ⚠️ 주의사항
- 본 도구는 학습 편의를 위해 제작되었습니다. 다운로드한 영상의 저작권은 해당 교수님 및 학교에 있으며, **무단 배포 및 상업적 이용은 법적 처벌을 받을 수 있습니다.**
- 개인의 아이디와 비밀번호는 로컬 환경의 `config.json`에만 저장되며 외부로 전송되지 않습니다.
